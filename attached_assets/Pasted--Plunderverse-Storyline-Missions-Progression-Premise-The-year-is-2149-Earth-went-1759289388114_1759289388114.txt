# 🌌 Plunderverse — Storyline, Missions & Progression

### **Premise**

The year is 2149. Earth went bust after corporations mined it like a piñata at a billionaire’s birthday party. Now, the Solar System is the new Wild West — full of half-broken colonies, outlaw havens, and planets littered with more scrap than a junkyard on Mars.

You are **Captain [Insert Player Name]**, a space pirate with a questionable résumé, a rusty ship that smells like fried coolant, and an unstoppable dream:
➡️ **To become the richest, most infamous pirate in the galaxy: the Space Pirate Supreme.**

---

## 🪐 Storyline Acts

### **Act I: Scrapheap Dreams**

* Start with a junker ship held together by duct tape and bad decisions.
* First missions: stealing oxygen tanks, mining “glow-rocks” that definitely aren’t radioactive, and running errands for shady traders.
* Introduced to rival pirate gangs with ridiculous names (e.g., “The Cosmic Crabs,” “Neptune’s Kneecappers”).

*Tone:* sarcastic NPC banter, missions that highlight how broke and unlucky you are.

### **Act II: Rise of the Rogue**

* Expand beyond asteroid belts into real planetary runs.
* Take on bounties, raid abandoned stations, and smuggle illegal snacks across moons (“Astro-Churros” are worth a fortune on Europa).
* Rival pirates start noticing you. Corporations put out bounties on your head.
* Your ship is upgraded enough to stop looking like a flying toaster.

*Tone:* gallows humor, corporate propaganda broadcasts that mock you, ridiculous loot descriptions.

### **Act III: Galactic Infamy**

* You’re a known problem now. Rival pirate bosses call you out. Corporations send fleets after you.
* Massive “heist-style” missions (steal fuel reserves from Saturn’s refineries, mine glowing crystals under Neptune’s storms).
* Crew loyalty tested (they want more credits, or at least less food poisoning).
* Slowly piece together your reputation as a serious contender for Pirate Supreme.

*Tone:* dark comedy, “fake epic” moments undermined by pirate bickering or ship malfunctions mid-battle.

### **Final Act: Space Pirate Supreme**

* Face off against the reigning Pirate Lord of the Plunderverse (a ridiculous, over-the-top villain who insists on monologues).
* Massive, multi-stage battle (fleet combat, boarding actions, final duel).
* If you win, you earn the crown, the credits, and the infamy.
* If you lose, you’re mocked forever in taverns across the galaxy.

*Tone:* parody of “epic space finales,” full of explosions, sarcastic one-liners, and a “you did it, now you’re broke again” twist.

---

## 🎯 Mission/Quest Structure

### **Early Game (Act I)**

* **Tutorial Loot Runs:** Steal oxygen tanks, salvage derelict drones.
* **Shady Deliveries:** Smuggle crates of suspicious “instant noodles” to a Mars outpost.
* **Bounty Board Intro:** Catch a low-level rival who’s wanted for unpaid bar tabs.

### **Mid Game (Act II)**

* **Station Heists:** Disable security to loot energy cores.
* **Mining Ops:** Deploy drones to harvest volatile crystals before they explode.
* **Corporate Raids:** Hijack supply freighters and sell loot to black market traders.
* **Crew Loyalty Missions:** Side quests where your crew demand upgrades, better rations, or revenge against rivals.

### **Late Game (Act III)**

* **Multi-Stage Heists:** Example — infiltrate Saturn’s refinery, steal antimatter fuel, escape corporate fleets.
* **Faction Wars:** Choose to ally with rival pirate factions or betray them all.
* **High-Stakes Bounties:** Missions where failure means permanent ship damage or crew loss.

### **Final Act**

* **Fleet Showdown:** Coordinate allies, fight corporate fleets, rival pirate bosses, and finally the reigning Pirate Lord.
* **End Choice:** Retire rich, keep raiding forever, or sell out to a mega-corp for “consulting fees.”

## ⚙️ Progression System

### **Player Rank (Titles)**

* **Rogue → Raider → Corsair → Captain → Pirate Lord → Space Pirate Supreme**
* Rank increases unlock new missions, gear, and higher bounties on your head.

### **Ship Upgrades**

* **Engines:** Faster travel, chance to escape ambushes.
* **Weapons:** From “salvaged laser pointers” to railguns and plasma cannons.
* **Hull & Shields:** Improve survivability against corporate fleets.
* **Cargo Bay:** Bigger loot hauls, but more tempting for rivals.
* **Crew Quarters:** Unlock new crew members with perks.

### **Crew System**

* Recruitable NPCs with unique perks (and flaws):

  * **Engineer:** Repairs faster, but drinks all the coolant.
  * **Gunner:** Boosts ship combat, but picks fights with everyone.
  * **Trader:** Better prices at markets, but skims off the top.
* Loyalty can shift based on pay, food, and mission success.

### **Economy & Resources**

* **Credits:** Universal currency earned from missions and loot sales.
* **Minerals & Salvage:** Needed for repairs and crafting upgrades.
* **Fuel & Supplies:** Consumables for travel — run out, and you’re space debris.

### **Reputation System**

* Choices affect standing with factions:

  * **Pirates:** Gain infamy, unlock outlaw hubs.
  * **Corporations:** Earn higher bounties, more patrols hunt you.
  * **Civilians:** Some may help you, others rat you out.

## 🎭 Humor Style

* **Loot names:** “Slightly Used Plasma Rifle,” “Corporate Desk Chair (Deadly in Zero-G).”
* **NPC banter:** “Captain, we’re technically out of fuel, but hey — space is mostly coasting, right?”
* **Mission briefs:** delivered by shady quest-givers who forget your name, call you “Captain Dumpster Fire,” etc.
* **Running gag:** Your ship’s AI is sarcastic, lazy, and insists it was designed for “luxury cruises, not piracy.”

# 🧩 Implementation Spec — Plunderverse Core Loop (for AI Builder)

**Goal:** Implement the Plunderverse gameplay loop into an existing web game codebase with minimal disruption, providing clean interfaces, data contracts, and extension points for content, AI, and economy tuning.

## 1) Architecture Overview

* **Client (Web):** UI, input, rendering (canvas/WebGL), local sim tick, prediction.
* **Game Logic Layer:** Deterministic systems (travel, missions, mining, combat resolution, inventory, progression) driven by a **Turn/Tick** loop and **Event Bus**.
* **Content Layer:** JSON/CSV-driven definitions (planets, missions, items, factions, ranks, loot tables).
* **Services:** Persistence (save slots), RNG (seeded), Telemetry, Balancer (economy curves), AI Director.
* **Adapters:** Integrations to existing engine modules (Renderer, Audio, NetSync if any).

```
UI ↔ GameFacade ↔ Systems (Travel/Mission/Economy/Inventory/Progression)
                        ↕
                      EventBus
                        ↕
                  ContentRegistry
                        ↕
                  Persistence/Telemetry
```

## 2) Core Data Models (TypeScript Interfaces)

```ts
// Identity & Meta
type ID = string; // ulid() or uuidv7()

interface PlayerProfile {
  id: ID;
  name: string;
  rank: PlayerRankKey; // e.g., "rogue", "raider", ...
  credits: number;
  notoriety: number; // drives bounty level
  reputation: Record<FactionKey, number>; // -100..+100
  shipId: ID;
  inventory: Inventory;
  stats: ProgressStats;
}

interface Ship {
  id: ID;
  hull: number; hullMax: number;
  shields: number; shieldsMax: number;
  cargoCap: number; cargoUsed: number;
  fuel: number; fuelMax: number;
  modules: ShipModule[]; // engines, weapons, scanners, cargo, crewQuarters
}

interface ShipModule {
  id: ID; key: ModuleKey; tier: number; level: number;
  modifiers: StatModifier[];
}

interface StatModifier { key: string; op: "add"|"mul"; value: number; }

interface Inventory { items: ItemStack[]; }
interface ItemStack { itemKey: ItemKey; qty: number; }

interface Mission {
  id: ID; defKey: MissionKey; state: MissionState;
  origin: NodeKey; target?: NodeKey;
  objectives: Objective[]; deadline?: GameTime;
  rewards: Rewards; penalties?: Penalties;
  seed: number;
}

interface Objective { type: ObjectiveType; payload: any; progress: number; complete: boolean; }

type ObjectiveType = "MINE" | "BOUNTY" | "DELIVER" | "HEIST" | "SCAVENGE";

interface Rewards { credits?: number; items?: ItemStack[]; notoriety?: number; rep?: Partial<Record<FactionKey, number>>; }
interface Penalties { hull?: number; crewMorale?: number; rep?: Partial<Record<FactionKey, number>>; }

interface StarNode { key: NodeKey; kind: "planet"|"moon"|"belt"|"station"; risk: number; yield: YieldCurve;
  faction?: FactionKey; services: ServiceKey[]; travelCost: number; }

interface YieldCurve { mineral: number; salvage: number; bounty: number; anomaly: number; }

interface RankDef { key: PlayerRankKey; name: string; gate: RankGate; perks: StatModifier[]; }
interface RankGate { credits: number; notoriety: number; missionsCompleted: number; }

interface EconomyTuning {
  fuelBaseCost: number; repairBaseCost: number; sellBuySpread: number; // 0.0..1.0
  dropRates: Record<string, number>; // itemKey -> chance 0..1
  rarityMultipliers: Record<Rarity, number>; // affects price/rolls
}

// Time
type GameTime = number; // ticks or ms
```

## 3) State Machine — High-Level Flow

```
BOOT → LOAD_PROFILE → GALAXY_MAP
  → TRAVEL (fuel check, encounter roll)
  → LOCATION_SCENE
      → PICK_MISSION | FREE_ROAM
      → RESOLVE (Mining | Bounty | Heist | Delivery)
      → REWARDS → UPGRADES/REPAIR → GALAXY_MAP

At thresholds: RANK_EVAL → Rank Up → Unlocks
At notoriety: BOUNTY_ESCALATE → Ambush chance increases
```
